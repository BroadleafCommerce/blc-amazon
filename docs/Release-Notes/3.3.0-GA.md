# Amazon S3 Version 3.3.0-GA

_Released on September 5, 2024_

This is the initial release for the Broadleaf Amazon 3.3.x module.  This module requires Broadleaf Framework version 7.0.0-GA or greater.

# An at-a-glance view of the issues that were closed in this release:

### Features(2)
- Upgraded AWS sdk to S3 and AWS-JAVA to 2.23.1
- Upgraded module to Jakarta EE to make to compatible with BLC-7.0 and Spring 6.0
